# datacenter-water-electricity-pyspark

Global Data Center Electricity & Water Usage — PySpark Analysis
A PySpark project analyzing electricity and water consumption across 18,110 real data center facilities worldwide from 2019 to 2025.

Dataset: Global Data Center & AI Water/Electricity Usage — Kaggle.
https://www.kaggle.com/datasets/ashyou09/global-data-center-and-ai-waterelectricity-usage/data


| Column | Description |
|---|---|
| `Year` | Data record year (2019–2025) |
| `Facility_ID` | Unique facility identifier |
| `Facility_Name` | Data center name |
| `Owner_Company` | Facility owner/operator |
| `City` | Facility city |
| `Country` | Facility country |
| `Facility_Type` | Hyperscale/AI, Colocation, or Enterprise |
| `Estimated_Capacity_MW` | Estimated electrical capacity |
| `PUE` | Power Usage Effectiveness |
| `Cooling_System_Type` | Cooling technology category |
| `WUE_L_per_kWh` | Water Usage Effectiveness |
| `Daily_Electricity_Usage_MWh` | Estimated daily electricity consumption |
| `Daily_Water_Usage_Gallons` | Estimated daily water consumption |
| `Surrounding_Water_Stress_Tier` | Regional water stress classification |
